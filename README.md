# aliaogoogle
阿廖顧狗

## 目前進度

- 畫面風格為「精緻像素」（另有 `?style=retro`、`toon`、`soft` 可比較）
- 客廳、走廊、狗房、廁所與廚房的 3D 模型（依照片與手繪平面圖估計尺寸），一打開是人的視角（從大門進來），可切換俯瞰／人／狗／貓視角，左上角可切換房間
- 房間的平面放大 1.25 倍（`js/kit.js` 的 `SPACE`），家具維持原尺寸：靠牆的家具繼續貼著牆，房間中間的照比例移開（`js/layout.js`）；各房間的程式仍照原本估計的尺寸寫
- 一天的流程（`js/flow.js`）：第一次進站有教學，之後依序帶著做三個主線任務，中間穿插貓咪的突發事件（支線任務）；進度會記住，右上「今天 x/5」可叫回下一件事
- 和巴福柔互動（`js/play.js`）：走到牠旁邊點牠，可以握手、趴下、踹人、被人騎、點穴（人會隨機出現痠痛或坐骨神經痛，請牠按一按就會緩解）
- 巴福柔和兩隻貓（一大一小）會在整個屋子裡隨機走動（`js/wander.js`）
- 廚房門口的寵物柵欄平常關著，點一下開關；開著離開廚房會跳出警示（`js/gate.js`）
- 客廳電視（`js/tv.js`）：走到電視前會問要不要看「災」，要看就在電視上輪播劇照（`assets/tv/`），可放大看或關掉
- 音效與震動（`js/sound.js`）：全部用 Web Audio 現場合成，不需要音檔；拿東西、沖馬桶、倒飼料、狗叫貓叫、被踹、點穴等都有聲音，手機上會震動。底部「♪ 聲音」可以切成靜音
- 任務回饋（`js/feedback.js`）：每完成一個步驟有提示音、目標文字閃一下；整個任務完成時放彩帶、跳出完成橫幅，巴福柔會開心地跳一跳
- 左上「散步圖集」：隨時看散步路線的 17 張街景照片與說明（縮圖一覽，點進去可前後翻）
- 任務一「帶狗出門」：屋內三個步驟在 `js/mission.js`，出門後依序顯示的街景照片與說明文字在 `js/walk.js`，街景照片放 `assets/walk/`
- 任務二「清潔時間」（`js/clean.js`）：撿起三塊用過的尿布墊（走廊一塊、狗房廁所兩塊）→ 到廁所東牆層架拿新墊鋪回原位 → 撿便便（隨機 0～2 坨，沒有就跳過）→ 包起來丟馬桶沖掉 → 從廚房後門把舊墊拿出去丟
- 任務三「餵狗」（`js/feed.js`）：拿狗碗 → 裝飼料（白色櫃子背後的綠色飼料袋）→ 裝凍乾（松木層架上的白色罐子）→ 巴福柔自己走過去吃，吃完走回原位
- 支線任務（`js/side.js`）：清理貓砂（抽屜拿藍色塑膠袋 → 廚房挖貓砂 → 後門丟掉）、餵貓（廚房飼料桶 → 倒進兩個鐵碗）

## 程式結構

- `js/main.js`：組裝場景、視角切換、點擊走路、主迴圈
- `js/quest.js`：所有任務共用的骨架（階段、黃色菱形、完成紀錄）；各任務只描述自己的物件與步驟
- `js/nav.js`：可走範圍、找路、沿路走、轉身等共用工具
- `js/post.js`：畫面後製（像素化、色階、描邊）；`js/leash.js`：牽繩；`js/compass.js`：目標方向箭頭
- `js/kit.js`：建模工具（方塊、貼圖、點擊範圍）與畫面風格設定；`js/layout.js`：把屋子換算成實際大小

## 本機預覽

純靜態網頁，不需要建置。因為使用 ES module，需透過本機伺服器開啟：

```bash
python3 -m http.server 8000
```

然後開啟 http://localhost:8000
